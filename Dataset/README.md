# Dataset – DataCo Smart Supply Chain

## Dataset Overview

This project uses the **DataCo Smart Supply Chain for Big Data Analysis** dataset, a publicly available supply-chain dataset hosted on Kaggle.

The dataset represents supply-chain activities covering areas such as:

* Provisioning
* Production
* Sales
* Commercial distribution
* Customer transactions
* Product information
* Shipping and delivery
* Financial performance

The dataset is suitable for analyzing **sales performance, profitability, customer behavior, shipping performance, delivery risk, regional performance, and supply-chain operations**.

## Dataset Source

**Kaggle:** DataCo Smart Supply Chain for Big Data Analysis

[Download Dataset from Kaggle](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis?utm_source=chatgpt.com)

The dataset was originally associated with work by **Fabian Constante, Fernando Silva, and António Pereira**, with the Kaggle page referencing the corresponding Mendeley Data source.

## Dataset Files

The Kaggle dataset contains:

| File                               | Description                                              |
| ---------------------------------- | -------------------------------------------------------- |
| `DataCoSupplyChainDataset.csv`     | Main structured supply-chain transaction dataset         |
| `DescriptionDataCoSupplyChain.csv` | Description of the variables/columns in the main dataset |
| `tokenized_access_logs.csv`        | Unstructured clickstream/access-log data                 |

For this project, the primary file used is:

```text
DataCoSupplyChainDataset.csv
```

The project focuses on the structured transaction data rather than the clickstream file.

## Dataset Size

The main dataset contains approximately:

```text
Rows    : 180,519
Columns : 53
```

The dataset contains transaction-level information that can be used to study the complete order and shipping process.
